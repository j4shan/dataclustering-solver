DERIVATION (every printed value comes from this)
For the group with n records:

  np = mean(selected_per_query)                 # lambda at K = 1
  K_max = floor(n / size_floor)                 # the chain is 1 .. K_max
  lambda(K) = np / K
  Pr_empty(K) = exp(-lambda(K))
  V(K) = n * Pr_empty(K)                        # expected data skipping volume

  marginal efficiency, one unit step of the chain:
    e(K) = delta_V / delta_K = V(K + 1) - V(K)  with delta_K = 1

  concavity:
    d2V/dK2 = V(K) * (np / K^3) * (np / K - 2)
    The figure writes this expression in n and p. It does not use the
    lambda symbol here, even though np / K is that parameter.
    Only the bracket can turn negative, so the sign flips at np / K = 2:
    K_0 = np / 2                                # the inflection
    K < K_0  convex   e rising   greedy has no guarantee
    K > K_0  concave  e decaying the region the theorem needs

  K_skip = np / ln(1 / typical_skip_bar) = np / ln 2
