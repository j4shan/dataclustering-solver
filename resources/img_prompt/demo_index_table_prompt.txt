PRODUCTION
Render each frame at 2× and downsample (LANCZOS) so small type and the 3px Blob
dots stay clean. Draw the static scene once and redraw only the shafts per
frame, so the frames differ in the arrow region alone and APNG inter-frame
deltas keep the file near 1.2 MB. Every header name must clear its column, the
card must keep ≥18px from both tables, and the event table must stay on canvas —
fail the render rather than clip.
