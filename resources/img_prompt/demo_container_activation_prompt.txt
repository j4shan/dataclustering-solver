ANIMATION — sequenced highlight
The highlight travels the operation once per cycle, in reading order:
  1 Query  →  2 Activated container c₁  →  3 Materialized for q
It is a sweep, not a throb: no element pulses on its own, and nothing repeats
in place. Five beats, each lighting one actor:

  beat   actor                                        phase centre
  1      query chip border                            0.00
  2      the FETCH lane from chip to c₁               0.15
  3      container c₁ border + its selected tile e₂   0.32
  4      the fetch arrow from c₁ to the tray          0.50
  5      tray border + all three tiles inside it      0.68

Per frame k of 15, with phase φ = (k mod 14) / 14, each actor's intensity is a
raised cosine centred on its own phase:
  d = circular distance from φ to the centre
  l = 0 when d ≥ 0.20, else 0.5 · (1 + cos(π · d / 0.20))
The ±0.20 half-width makes neighbouring beats overlap, so the light is handed
along the chain instead of blinking on and off. It overlaps at the seam as well:
the tray has gone dark by phase 0.88, by which point the query chip is already
rising, so the pass hands back to its own start rather than resetting through a
dark frame. With these five centres and this half-width no frame is entirely
unlit, and none should be. Because the phase is k mod 14, frame 15 reproduces
frame 1 exactly.

How an actor is lit:
  · border colour interpolates from its resting colour toward #B8394E by
    0.45 + 0.55 · l, drawn at 2.6–3.0px over the resting border
  · a rounded-rect ring outside it, Gaussian-blurred ~4px, alpha up to 150 · l,
    standing off 5 → 12px
  · arrows are redrawn along the same path at 3px in the peak colour, their
    arrowheads included; the geometry never moves
Resting borders stay drawn in the base image, so an unlit actor looks exactly
like the static design. Stroke geometry is identical lit or unlit — only colour
and halo change, so nothing jitters or reflows.

Beat 5, in the tray, colours by role:
  · the selected event e₂ takes the wine highlight, as in beat 3
  · BOTH waste events e₁ and e₃ take a BLACK border (#0B0B0B) with a black
    halo — the beat reads "three events arrived: one kept, two waste"

Never lit: the skipped container c₂, its tiles, the dark-green lane, and any
text. The sweep traces what the query did; c₂ is what it did not do.
No other animation: no flowing dashes, no marching arrows, no moving chevrons.

Typesetting: no Unicode subscript characters. Set every subscript as a real

second level at ~0.54 em and ~0.46 em for the nested index in c₁ / c₂. The

carries it. A glyph the face lacks must never reach the raster, as a .notdef
box or as blank space.
