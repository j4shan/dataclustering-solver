SUBJECT
Spark Dynamic Partition Pruning on the index written in the ingestion
figure. The figure teaches one mechanism: a multi-select query prescans
the narrow index, collects a set of partition_id values, and Spark DPP
broadcasts that set to each worker as a metadata filter that trims
which cloud objects are downloaded. It is the illustration of Go Live
on Databricks Lakehouse §2.6. It is not a query planner, a join
diagram, or a measured runtime.

racks, or emojis. System-ui labels; ui-monospace for every identifier,

The same dictionary as
resources/img_prompt/c_data_ingestion_prompt.txt. Do not invent a

stream = "brand sales"
index_columns = ["brand_id", "pricing_tier", "partition_id"]
records = [
  {"record_id": "r01", "brand_id": "A", "pricing_tier": 1,
   "sku": "brk-12", "amount": 40, "partition_id": "p1"},
  {"record_id": "r02", "brand_id": "A", "pricing_tier": 2,
   "sku": "flt-03", "amount": 18, "partition_id": "p2"},
  {"record_id": "r03", "brand_id": "B", "pricing_tier": 1,
   "sku": "brk-08", "amount": 55, "partition_id": "p3"},
  {"record_id": "r04", "brand_id": "B", "pricing_tier": 2,
   "sku": "tyr-21", "amount": 22, "partition_id": "p4"},
]

query = {
  "text": "brand_id IN (A, B) AND pricing_tier = 1",
  "kind": "multi-select",
}

workers = ["w1", "w2"]

A row matches when its brand_id is A or B and its pricing_tier is 1.
The event table is not drawn on this figure; the download target is
the cloud object named by partition_id.

DERIVATION
  match(r)     = r["brand_id"] in {"A", "B"} and r["pricing_tier"] == 1
  activated    = distinct partition_id of matching rows
                 # {p1, p3}
  trimmed      = distinct partition_id of records minus activated
                 # {p2, p4}
  index_row(r) = {k: r[k] for k in index_columns}

Fail the render if activated is not exactly {p1, p3}, if trimmed is
not exactly {p2, p4}, or if a worker receives a set other than
activated.

PRODUCTION
Draw at 3840 x 2160 and downsample once to 1920 x 1080 with LANCZOS.
Load SFNS.ttf and SFNSMono.ttf from /System/Library/Fonts; select
weight with set_variation_by_name and cache by (size, weight, mono).
Use anchor= for text. Draw arrowheads and object glyphs as line
glyphs, not Unicode.

The index table uses the same column widths as the ingestion figure
so the two pages read as one family. Workers share size. Object
glyphs share size and baseline. Labels must clear arrow shafts by
at least 20 source pixels. Fail the render on clipping, overlap, a
bare column name, an activated set other than p1 and p3, a worker
arrow missing its set tag, a download mark on p2 or p4, a skip mark
on p1 or p3, or a drawn machine. After rendering, read the PNG back
and inspect it visually before acceptance. The PNG at the accepted
path is rendered and accepted from this specification; the renderer
that produced it is deleted with acceptance. A later visual change
starts a new authoring pass.
